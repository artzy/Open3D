# 큰 면 클러스터 분할 + 시야 면 필터 (2026-07-15)

## 배경

한 물체 한 면을 수 분간 스캔해도 `tracked 0`으로 region이 생기지 않았다.

원인:

1. `ProcessExtractedSurface`가 AABB max extent > `max_cluster_extent_m`(기본 1.2 m)이면 silent discard
2. region extract가 frozen만 제외한 맵 전체 surface를 넣어 벽·바닥이 한 DBSCAN 덩어리로 합쳐짐

## 구현

### A. 시야 면 필터

- Region 전용 extract weight: `RegionParams.extract_weight` (기본 3.0), CLI `--region_extract_weight`
- 카메라 원점(`T_frame_to_model` translation) 기준 유클리드 거리 밴드
  - `--region_depth_min` (기본 0.3 m)
  - `--region_depth_max` (기본 `min(2.5, depth_max)`)
- 헬퍼: `FilterPointCloudByCameraDistance` (`ObjectMeshPipeline.h`)
- 로그: `Region surface filtered: N -> M points (weight=W, depth=[min,max] m).`

### B. 초과 클러스터 AABB 그리드 분할

- extent > `max_cluster_extent_m`이면 discard 대신 타일 분할
- 타일 한 변 = `max_cluster_extent_m` (기본 1.2, CLI `--region_max_extent`)
- `min_cluster_points` 미만 타일 폐기
- 로그: `Region cluster split: extent=X m -> N tiles (kept M)`
- OnlineSLAM file playback의 `max_cluster_extent_m = 2.5`는 재생 전용으로 유지
