# Reloc 바디 상대 HUD + 주황 화살 (2026-07-16)

## 목표

Tracking lost 시 모델 좌표 dX/dY/dZ·얇은 가이드 선 대신, **last_stable 수평 yaw 기준** 안내 문구와 **주황 3D 화살**로 마지막 정상 포즈로 돌아가기 쉽게 한다.

## 축 정의

- 월드 up: `(0, -1, 0)` (SceneWidget LookAt과 동일)
- `forward_h`: last_stable 카메라 +Z를 수평면에 투영 (퇴화 시 +X 수평 폴백)
- `right_h = forward_h × up`
- `v = p_last_stable − p_current`
  - `fwd = v · forward_h`, `right = v · right_h`, `up = v · up`
- turn: 현재 수평 forward와 `v` 수평 성분 사이 각 (`turn left/right N deg`)
  - 수평 거리 < 5 cm 이면 turn 줄 생략

## HUD 문구 예시

```
Return to orange
fwd   0.42 m
left  0.15 m
up    0.05 m
dist  0.45 m
turn left 18 deg
```

부호는 `fwd/back`, `left/right`, `up/down` 절대값 + 방향 단어로 표기.

## 3D 표시

| 요소 | 내용 |
|------|------|
| 주황 frustum | last_stable, scale **0.35** |
| 청색 frustum | current, scale **0.18** |
| 주황 화살 | current → last_stable (샤프트 + 4분지 tip), 거리 &lt; 2 cm 이면 숨김 |
| 패널 제목 | `Return guidance` |
