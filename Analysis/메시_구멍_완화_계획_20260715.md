# 메시 구멍 완화 — 스캔 가이드 및 1차 구현 (2026-07-15)

## 목표

region commit mesh의 국소·경계 구멍을 줄인다. 완전 메움이 아니라 **조기 구멍 mesh 커밋 억제 + seam sanitize 완화**.

## 1차 기본값

| 항목 | 값 |
|------|-----|
| `min_readiness` | 0.80 |
| `max_void_ratio` | 0.08 |
| `max_void_blob_cells` | 32 |
| `max_boundary_void_ratio` | 0.10 |
| seam sanitize edge factor | 1.20 |
| 권장 profile | **medium** |

## CLI

- `--region_min_readiness`
- `--region_max_void_ratio`
- `--region_max_void_blob`
- `--region_max_boundary_void`

commit이 과도하게 막히면 예: `--region_min_readiness 0.75 --region_max_void_ratio 0.10`

## 권장 실행 (품질)

```bat
cd D:\study\Open3D\SLAM\bin\Release
.\RealTimeSLAMRealSense.exe --regions -c d:\study\Open3D\examples\test_data\rs_d415_slam.json --profile medium --depth_max 3 --region_interval 45 --region_stability 5 --region_min_points 3000
```

## 스캔 팁

1. 천천히 이동, 구멍 난 면을 여러 각도로 재관측
2. 반사·검은 면은 조명/각도 변경
3. 한 구역을 충분히 채운 뒤 다음으로 이동
4. `deferred (void|holey)` 로그가 늘면 게이트가 구멍을 막고 있는 것

## 기대 로그

```
Region candidate N deferred (void): void_ratio=.. (before_sanitize=.. after=..)
Region candidate N committed (..., void=0.05->0.06, boundary_void=..)
```

## 2차 (미구현)

- 소형 boundary hole-fill
- 대형 void 재관측 유도 / Unfreeze
- 오프라인 scene_mesh hole fill 도구 가이드
