# 빈 표면(Mesh Hole/Gap) + 정지 시 Mesh 금지 통합 정책

날짜: 2026-07-14

## 목표

- 카메라가 정지/노이즈 수준이면 point→mesh(freeze/commit) 금지
- 국소 void(내부 구멍)와 경계 void(region 간 갭)를 같은 hard reject로 처리
- 기존 holey-defer·seam dilation 유지, Unfreeze는 이번 단계에서 추가하지 않음

## 변경 파일

| 파일 | 내용 |
|------|------|
| `SLAM/cpp/ObjectMeshPipeline.h` | net pose + hash + warmup 게이트, void report, sanitize, seam remesh |
| `SLAM/cpp/RealTimeSLAMRealSense.cpp` | motion anchor, region queue skip, seam upsert, CLI |
| `SLAM/cpp/OnlineSLAMUtil.h` | 동일 게이트·seam upsert |
| `SLAM/cpp/OnlineSLAMRGBD.cpp` | CLI |

## Commit 조건

```
IsValidRegionMesh
AND camera_moved (non-flush)
AND void_ratio <= 0.12
AND max_void_blob <= 48
AND boundary_void_ratio <= 0.15
AND readiness >= min_region_readiness (holey defer)
→ FreezeBlocks + Save + 이웃 seam remesh/upsert
```

## Motion 게이트 (추천 조합, 2026-07-14)

### 문제
프레임별 odometry를 합산하면 정지 상태에서도 노이즈가 random-walk처럼 누적되어
`min_motion_m=0.03`을 쉽게 넘김 → 정지 중에도 region mesh 큐잉.

### 해결 (AND 조건)

1. **Net pose vs anchor** — `T_anchor⁻¹ * T_cur`의 병진/회전 (합산 금지)
2. **Hash growth** — `Δhash ≥ min_hash_delta_blocks` (기본 2) 와 pose를 함께 요구
3. **임계값** — 기본 `0.05 m` / `8°`
4. **Warmup** — 처음 `region_motion_warmup_frames` (기본 45) 프레임은 region mesh skip
5. 성공 큐잉 후 anchor를 현재 pose/hash로 리셋

```
pose_ok = (net_t >= 0.05) OR (net_r >= 8°)
hash_ok = (hash_cur - hash_anchor) >= 2
warmup_ok = frame_id >= 45
camera_moved = require_camera_motion ? (warmup_ok AND pose_ok AND hash_ok) : true
```

## CLI

- `--region_min_motion_m 0.05` — anchor 대비 net 병진 (m)
- `--region_min_motion_deg 8` — anchor 대비 net 회전 (deg)
- `--region_min_hash_delta 2` — hash block 증가 최소값
- `--region_motion_warmup 45` — 초기 region mesh 스킵 프레임 수
- `--region_allow_stationary_mesh` — 정지 중 mesh 허용 (기본 OFF)
- 기존 `--region_min_readiness`, `--region_max_holey_defer`, `--region_no_holey_defer`

## 기대 로그

- `Region check skipped: motion warmup (frame N/45, net t=.., dhash=..)`
- `Region check skipped: camera nearly stationary (net t=.. r=.. dhash=..)`
- `Region segmentation queued at frame N (... net t=.., dhash=..)`
- `Region candidate N deferred (void): void_ratio=.. max_blob=.. boundary_void=..`
- `Updated region N seam strip after neighbor M commit.`
